NEXTGEN mPARIVAHAN — UI / NAVIGATION POLISH V1.3

This update specifically addresses the reported logo, icon, text-overlap and navigation problems.

VISUAL ASSET FIXES
- Replaced the old screenshot-cropped header logo (which contained stray status-bar symbols) with a clean crop from the supplied reference header.
- Added high-density (xxhdpi) logo and service-icon resources for sharper rendering on modern Android phones.
- Removed the old text fragments embedded at the bottom of several icon images.
- Increased service icon display size and preserved the image aspect ratio.
- Added a matching app launcher icon.

LAYOUT / TYPOGRAPHY
- Increased quick-access and service-grid row height to accommodate three-line labels.
- Made service labels wrap naturally rather than forcing them into a short fixed-height line.
- Standardized font rendering defaults and line breaking to reduce clipped or overlapping text.
- Made service list cards and feature cards grow with their content.

NAVIGATION
- Added bottom navigation to Nearby Services, Emergency Service, My Transactions and Raise a Complaint.
- Kept the back arrow in subpage headers and Android system Back handling.
- Added a short fade transition when opening and restoring screens.
- Replaced emoji drawer symbols with consistent monochrome glyphs.

BUILD CONFIGURATION
- App version: 1.3 (versionCode 4)
- Android Gradle Plugin: 8.7.3
- Gradle wrapper: 8.9
- Java: 17
- compileSdk: 35 / minSdk: 23 / targetSdk: 35

VALIDATION
- Project root contains settings.gradle and build.gradle.
- ZIP integrity is checked before delivery.
- A full Android Gradle build and device screenshot test were not available in this environment; please run Gradle Sync and test on an emulator/device before presenting it as a tested build.

This remains an offline portfolio demonstration. Government transport lookups, submissions, notifications and payments are not live integrations.
