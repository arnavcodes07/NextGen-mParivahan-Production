These tools/dependencies (Android SDK, Gradle distribution, Maven dependencies) are not installed in this preparation environment. The generated ZIP must be built and tested on the user's Android Studio/Windows setup.

Critical limitations before production:
- Demo MPIN is stored and compared as plaintext; no token/session authorization, per-user endpoint authorization, rate limiting, lockout, OTP or audit controls.
- Registration and MPIN reset return MPIN in API response.
- Production database schema migration strategy is not yet implemented.
- Nearby and emergency data are static demo responses; complaints are only saved locally and not submitted to any authority.
- No official government integrations or live payment/OTP services.
- Do not expose the demo API to the public internet or publish a release until production security work is complete.
